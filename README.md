# 📱 SportApp

**SportApp** es prototipo de una aplicación Android enfocada en la planificación, seguimiento y motivación del entrenamiento personal.
Esta aplicación ha sido desarrollada como parte de una practica de la asignatura de Interacción hombre máquina 

## 🏋️ Funcionalidades principales

- **Planificación de entrenamientos:** permite al usuario crear sesiones personalizadas con ejercicios, series, repeticiones y peso.
- **Visualización de sesiones:** muestra el contenido de cada planificación con detalle.
- **Entrenamiento guiado:** incluye temporizador, contador de series y opciones de peso seleccionable.
- **Resumen de actividad:** presenta un resumen del último entrenamiento y un análisis semanal con tiempo total, series realizadas y calorías estimadas.
- **Sistema de trofeos:** otorga logros visuales por hitos como completar entrenamientos o mantener la constancia.
- **Navegación intuitiva:** acceso directo a las secciones principales mediante una barra inferior y barra superior.

## 🎨 Diseño y usabilidad

- Interfaz adaptada al dispositivo **Nexus 6 (API 27)**.
- Colores contrastados para facilitar la lectura.
- Íconos visuales para reforzar la navegación y comprensión rápida de funciones.
- Diseño responsive con `ConstraintLayout` y `LinearLayout`.

## 🛠 Tecnologías utilizadas

- **Lenguaje:** Kotlin
- **Entorno:** Android Studio
- **UI:** XML layouts, drawable resources, estilos y temas personalizados
- **Componentes:** Activities, intents, listeners, y navegación modular
